# 颐和园旅游介绍网站 - 颐园印象

一个沉浸式的颐和园文化旅游数字平台，展示世界遗产价值、皇家园林艺术和深厚历史文化底蕴。

## 功能特性

### 核心功能
- **沉浸式首页** - 全屏视差滚动背景，品牌文化传达
- **扑克牌式景点卡片** - 8大核心景点的创意堆叠翻页展示
- **景点详情页** - 文化介绍、风景图、实物档案
- **互动地图导览** - 景区地图标注、地点导航
- **四季风景展示** - 春夏秋冬不同季节的特色景观
- **旅游攻略模块** - 交通、美食、住宿、特产实用信息
- **响应式设计** - 适配桌面端和移动端访问

### 8大核心景点
1. 佛香阁 - 全园标志建筑
2. 长廊 - 世界最长画廊
3. 十七孔桥 - 金光穿洞奇观
4. 排云殿 - 慈禧庆寿之所
5. 谐趣园 - 园中之园
6. 清晏舫（石舫）- 西洋风格建筑
7. 乐寿堂 - 慈禧寝宫
8. 德和园大戏楼 - 清代三大戏台

## 技术栈

- **框架**: React 18
- **构建工具**: Vite 5
- **类型系统**: TypeScript 5
- **样式方案**: Tailwind CSS 3
- **路由管理**: React Router 6
- **状态管理**: Zustand 4
- **动画库**: Framer Motion 11
- **图标库**: Lucide React

## 设计理念

### 设计风格
- **新中式 + 现代简约**
- 色彩：中国传统色彩（朱红、琉璃黄、墨绿、象牙白）
- 字体：书法风格标题 + 现代无衬线正文
- 大量留白，营造园林"移步换景"的空间感

### 色彩方案
- **主色调**: 皇家红 `#8B1A1A`
- **辅助色**: 琉璃黄 `#D4A574`
- **自然色**: 园林绿 `#2D5A3D`, 昆明湖蓝 `#4A7C8C`
- **背景色**: 宣纸米 `#F5F0E8`

## 使用说明

### 景点卡片交互
- 滚动鼠标滚轮或使用键盘上下箭头切换景点
- 点击卡片进入详情页
- 点击底部指示器快速跳转

### 互动地图
- 拖拽移动地图
- 点击缩放按钮或使用鼠标滚轮缩放
- 点击景点标记查看详情
- 使用筛选器按类型查看景点

### 季节切换
- 点击季节标签切换查看不同季节的特色景观
- 每季包含最佳游览时间和摄影攻略

## 开发指南

### 组件开发
- 组件文件使用 `.tsx` 扩展名
- 每个组件保持在 300 行以内
- 使用 Framer Motion 处理动画效果
- 遵循 Tailwind CSS 原子化样式

### 状态管理
- 使用 Zustand 进行全局状态管理
- 景点和季节数据存储在 store 中
- 页面级状态使用 React useState

### 样式规范
- 使用 Tailwind CSS 工具类
- 自定义颜色和字体在 tailwind.config.js 中配置
- 全局样式在 src/index.css 中定义
